# Fundamentos de Python

## 📚 Descripción

En este proyecto se recopilan diferentes ejercicios enfocados en el aprendizaje de **Python**, con el objetivo de adquirir y fortalecer las bases esenciales del lenguaje.

## 🎯 Temas

- **Variables**
- **Cadenas de texto**
- **Tipos de datos**
- **Estructuras condicionales:** `if`, `elif`, `else`
- **Operadores de comparación:** `<`, `>`, `==`, `!=`
- **Operadores aritméticos:** `+`, `-`, `*`, `/`
- **Expresiones lógicas:** `and`, `or`
- **Ciclos:** `for`, `while`
- **Turtle**

## 🎯 Objetivo

Fortalecer los conocimientos fundamentales de **Python** mediante ejercicios prácticos.
